## 🎯 Aim
To write a Python program that prints the characters `'T'` and `'a'` using character literals.

## 🧠 Algorithm
1. Print the character `'T'`.
2. Print the character `'a'`.

## 🧾 Program
ch1='T'

ch2='a'

print(ch1)

print(ch2)
## Output
T

a
## Result
Thus,the python program to print the characters 'T' and 'a' using character literals was written and executed successfully.
